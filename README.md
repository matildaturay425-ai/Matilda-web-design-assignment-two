​Project Overview
​Salone Taste Kitchen is a mid-priced family restaurant concept based in Freetown, Sierra Leone. The restaurant serves authentic local delicacies—including Cassava Leaf, Jollof Rice, Fried Plantain, and Grilled Fish—while offering dine-in, takeaway, and event catering services.

​This web design project transitions the restaurant from relying solely on informal social media updates (Facebook and WhatsApp) to a modern, structured, and mobile-friendly web presence.

​Problem Statement
​Unclear Pricing & Menu Information: Customers struggle to find an up-to-date menu with transparent prices in local currency (Le).
​Booking Inefficiencies: Informal table reservations made over phone calls often lead to missed bookings or scheduling conflicts.
​Fragmented Information: Essential details such as opening hours, precise street address, and contact links are scattered across old social media posts.
​Lack of Credibility: The absence of an official website reduces customer confidence, particularly among tourists, NGO consultants, office teams, and diaspora visitors.
​Proposed Solution
​A responsive, mobile-first web interface designed to streamline customer interaction:
​Transparent Menu: Categorized food options with real photos, descriptions, and clear pricing in Leones (Le).
​Online Reservation & Ordering: A simplified form allowing users to book tables or place takeaway orders quickly.
​Trust & Credibility Signals: Integrated photo gallery, team introductions, and clear restaurant values.
​Direct Accessibility: Clear map visuals, verified opening hours, and direct phone/WhatsApp contact options.
​Fast Performance: Lightweight pages optimized to load smoothly even on limited mobile data connections.
​Target Users & Key Needs
​The platform serves diverse user groups in Freetown including young professionals, families, event planners, and visiting tourists. Key needs addressed by the website include:
​Viewing complete food & beverage menus with transparent pricing before visiting.
​Booking tables online without making long phone calls.
​Accessing clear opening hours and location maps for easy navigation.
​Conveniently ordering takeaway meals or requesting event catering services.
​Key Design System & Color Palette
​The site uses a warm, appetizing palette inspired by traditional Sierra Leonean hospitality and local spices:
​Primary Brand Accent (#d96b27): Warm Amber / Burnt Orange for call-to-action buttons, active navigation links, and pricing.
​Hover State Accent (#b8541c): Richer orange accent for interactive focus states.
​Headings Tone (#3d1c10): Dark Espresso Brown for titles (h1, h2, h3) ensuring high typographic contrast.
​Body Text (#2c2c2c / #666666): Charcoal grey for comfortable readability.
​Page Background (#fcf8f2): Soft warm cream reducing eye strain.
​Card & Highlight Box Background (#fbf6f0): Subtle beige tone for grouped content cards and form panels.
​Borders & Dividers (#f7ebd7): Light warm beige for subtle structural separation.
​Key Features & Technical Highlights
​Embedded CSS Design: Styles are embedded directly within each page's <head> section (<style>), allowing every HTML page to run standalone.
​Responsive Multi-Page Architecture: Adaptive CSS Grid and Flexbox layouts built to fit screens ranging from mobile phones to desktop displays.
​Live Visual Assets: Embedded high-resolution web imagery served dynamically via Unsplash links.
​Form UI Interactivity: Styled table reservation, takeaway ordering, and contact enquiry forms with standard html input validations.
​How to Run the Project
​Save all 6 HTML files (index.html, about.html, menu.html, booking.html, gallery.html, and contact.html) together in a single folder.
​Double-click index.html to open the website in any web browser (Chrome, Edge, Firefox, or Safari).
​Ensure your computer/mobile device has an active internet connection to load the live image sources.
